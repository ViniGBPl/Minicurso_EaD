# Minicurso — Análise Crítica de Vieses em Conteúdos Educacionais com IA

Projeto Next.js 14 + Tailwind CSS, pronto para deploy na Vercel.

## Antes de publicar

1. Em `app/page.tsx`, troque `SEU_ID_DO_YOUTUBE` pelo ID do vídeo no YouTube.
2. No mesmo arquivo, troque o `href="#"` do botão de avaliação pelo link do Genially.
3. Complete a lista de **Referências** com as fontes usadas no vídeo.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra http://localhost:3000

## Deploy na Vercel

Opção A — pelo painel da Vercel:
1. Suba esta pasta para um repositório no GitHub.
2. Em vercel.com, clique em "Add New Project" e importe o repositório.
3. A Vercel detecta o Next.js automaticamente — não precisa configurar nada.

Opção B — pela CLI:
```bash
npm i -g vercel
vercel
```
